# 🎮 GameTalk — مكالمات صوتية خفيفة أثناء اللعب

تطبيق أندرويد يتيح لك ولصديقك **مكالمة صوتية مباشرة أثناء اللعب** (eFootball
أو أي لعبة أخرى)، مع **فقاعة عائمة صغيرة فوق اللعبة** للتحكم في الصوت.

## ✨ الميزات

| الميزة | الوصف |
|--------|-------|
| 🎙️ مكالمة صوتية P2P | WebRTC — الصوت يذهب مباشرة بين الهاتفين |
| 🫧 فقاعة عائمة | تظهر فوق أي لعبة — لمسة = كتم/تشغيل، ضغط مطول = إنهاء المكالمة |
| 📶 مؤشر الجودة | نقطة خضراء/صفراء/حمراء تعكس زمن الاستجابة RTT |
| 🔁 إعادة اتصال تلقائية | لو ضعفت الشبكة يعيد المحاولة تلقائياً بنفس الغرفة |
| 🔕 كتم من الإشعار | زر كتم وإنهاء داخل إشعار الشريط العلوي |
| ⚡ استهلاك خفيف | Opus بـ 24kbps + DTX ≈ 12 ميجا/ساعة فقط |

## 📲 التثبيت

1. انسخ `GameTalk-1.0.apk` إلى الهاتفين (واتساب/بلوتوث/كابل).
2. من الهاتف: افتح الملف ← اسمح بـ«التثبيت من مصادر غير معروفة» ← ثبّت.
3. أثناء أول تشغيل امنح التطبيق:
   - إذن **الميكروفون**
   - إذن **العرض فوق التطبيقات** (Overlay) — ضروري للفقاعة
   - إذن **الإشعارات** (اختياري)

## 🕹️ طريقة الاستخدام

1. **نشّط السيرفر** (مرة واحدة): ضع رابط سيرفرك في حقل «عنوان سيرفر الربط»
   (انظر `RENDER-DEPLOY-AR.md` في مجلد السيرفر).
2. **أنت**: اضغط «⚡ إنشاء غرفة جديدة» ← سيظهر رمز من 4 حروف.
3. **صديقك**: يكتب الرمز ويضغط «🤝 انضمام للغرفة».
4. عند نجاح الاتصال ستسمعان بعضكما مباشرة، وتظهر **الفقاعة الزرقاء**.
5. افتح لعبتك والعبوا — الفقاعة تبقى فوقها!

### التحكم بالفقاعة
- **لمسة واحدة**: كتم / إلغاء كتم صوتك
- **سحب**: تحريك الفقاعة لأي مكان (تتذكر مكانها)
- **ضغط مطول**: يظهر زر أحمر ✕ لإنهاء المكالمة
- **النقطة الصغيرة**: جودة الاتصال (أخضر=ممتاز، أصفر=متوسط، أحمر=ضعيف)

## ⚠️ ملاحظات

- يعمل الاتصال على معظم الشبكات (واي فاي + بيانات الهاتف) لأنه P2P مباشر.
  الحالات النادرة التي يكون فيها الطرفان خلف NAT صارم جداً قد تحتاج شبكة أفضل.
- استخدم **سماعات** إن استطعت لتجنب صدى الصوت.
- إذا ظل الرمز «بانتظار صديقك» طويلاً: تأكد أن صديقك كتب الرمز صحيحاً وأن
  سيرفر الربط مستيقظ (افتح رابط السيرفر في المتصفح مرة).

## 🔐 الأمان والخصوصية

- الصوت مشفّر تلقائياً (DTLS/SRTP — معيار WebRTC) ولا يمر بأي سيرفر.
- سيرفر الربط يرى فقط: رمز الغرفة والرسائل التقنية لثوانٍ أثناء التعارف.
- الغرفة تتطلب الرمز المكون من 4 حروف ولا ينضم لها شخص ثالث.

## 🛠️ البناء من الكود (اختياري)

```bash
# يتطلب: JDK 17 + Android SDK 34
./gradlew assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

مفتاح التوقيع المرفق (`app/gametalk.keystore`): كلمة السر `gametalk2026`.
للاستخدام الشخصي فقط — أنشئ مفتاحك الخاص لو نشرت على متجر Play.

## 📁 بنية المشروع

```
app/src/main/java/com/gametalk/voice/
├── MainActivity.kt      الواجهة العربية (إنشاء/انضمام/أذونات/حالة)
├── BubbleService.kt     خدمة المكالمة: الإشعار + الفقاعة + إعادة الاتصال
├── BubbleView.kt        الفقاعة العائمة (لمسة/سحب/ضغط مطول/مؤشر الجودة)
├── CallEngine.kt        محرك WebRTC (Opus منخفض البت + قياس RTT)
├── SignalingClient.kt   عميل WebSocket لسيرفر الربط
└── CallBus.kt           الحالة المشتركة بين الخدمة والواجهة
```
