# 🎮 GameTalk — مكالمات صوتية خفيفة أثناء اللعب

تطبيق أندرويد يتيح لك ولصديقك **مكالمة صوتية مباشرة أثناء اللعب** (eFootball
أو أي لعبة أخرى)، مع **فقاعة عائمة فوق اللعبة** للتحكم في الصوت وإرسال
رسائل سريعة قابلة للنسخ — **بدون أي سيرفر أو إعدادات**.

## ✨ الميزات

| الميزة | الوصف |
|--------|-------|
| 🎙️ مكالمة صوتية P2P | WebRTC — الصوت يذهب مباشرة بين الهاتفين مشفّراً |
| 🫧 فقاعة عائمة «اثنان في واحد» | ضغطة = قائمة (كتم + رسائل) — ضغط مطول = قائمة مع الإنهاء |
| 💬 رسائل سريعة قابلة للنسخ | أرسل كود الغرفة أثناء المباراة — تظهر عند صديقك 4 ثوانٍ مع زر نسخ ثم تختفي |
| 🌍 يعمل من أي مكان | نفس الشبكة أو شبكات مختلفة أو بين مدن/بلدان — التعارف عبر سحابة PeerJS المجانية |
| 📶 مؤشر الجودة | نقطة خضراء/صفراء/حمراء تعكس زمن الاستجابة RTT |
| 🔁 إعادة اتصال تلقائية | لو ضعفت الشبكة يعيد المحاولة تلقائياً بنفس الغرفة |
| 🔕 كتم من الإشعار | زر كتم وإنهاء داخل إشعار الشريط العلوي |
| 🎨 أيقونة احترافية | مايك نيون داخل فقاعة كلام (v1.2) |
| ⚡ استهلاك خفيف | Opus بـ 24kbps + DTX ≈ 12 ميجا/ساعة فقط |

## 📥 التحميل

من صفحة الإصدارات:
**https://github.com/latchidz/AGENT-Z-AI/releases**
— حمّل `GameTalk-v1.2.apk` وثبّته على الهاتفين.

## 📲 التثبيت

1. انسخ `GameTalk-v1.2.apk` إلى الهاتفين (واتساب/بلوتوث/كابل).
2. من الهاتف: افتح الملف ← اسمح بـ«التثبيت من مصادر غير معروفة» ← ثبّت.
   (يُثبّت فوق الإصدارات السابقة مباشرة بدون حذف)
3. أثناء أول تشغيل امنح التطبيق:
   - إذن **الميكروفون**
   - إذن **العرض فوق التطبيقات** (Overlay) — ضروري للفقاعة
   - إذن **الإشعارات** (اختياري)

## 🕹️ طريقة الاستخدام

1. **أنت**: اضغط «⚡ إنشاء غرفة جديدة» ← سيظهر رمز من 4 حروف.
2. **صديقك**: يكتب الرمز ويضغط «🤝 انضمام للغرفة».
3. عند نجاح الاتصال ستسمعان بعضكما مباشرة، وتظهر **الفقاعة الزرقاء**.
4. افتح لعبتك والعبوا — الفقاعة تبقى فوقها!

### التحكم بالفقاعة
- **ضغطة سريعة**: قائمة صغيرة فيها **زر الرسائل 💬** — والفقاعة نفسها = كتم/تشغيل
- **ضغطة على الفقاعة والموسعة**: كتم / إلغاء كتم صوتك
- **سحب**: تحريك الفقاعة لأي مكان (تتذكر مكانها)
- **ضغط مطول**: نفس القائمة + زر إنهاء المكالمة الأحمر
- **النقطة الصغيرة**: جودة الاتصال (أخضر=ممتاز، أصفر=متوسط، أحمر=ضعيف)

### الرسائل السريعة 💬
1. اضغط الفقاعة ← الزر الأخضر 💬 ← تفتح نافذة كتابة أعلى الشاشة.
2. اكتب الرسالة (كود الغرفة مثلاً) واضغط إرسال.
3. عند صديقك: بطاقة أعلى الشاشة فيها الرسالة + زر نسخ — لمسها = نسخ
   فوري، وتختفي تلقائياً بعد 4 ثوانٍ (مع اهتزاز ونغمة).
4. الرسائل تصل فقط أثناء المكالمة المتصلة، وتذهب مباشرة بين الهاتفين
   عبر قناة بيانات WebRTC مشفّرة — لا تمر بأي سيرفر.

## ⚠️ ملاحظات

- يعمل الاتصال على معظم الشبكات (واي فاي + بيانات الهاتف) لأنه P2P مباشر.
  الحالات النادرة التي يكون فيها الطرفان خلف NAT صارم جداً قد تحتاج شبكة أفضل.
- استخدم **سماعات** إن استطعت لتجنب صدى الصوت.
- إذا ظل الرمز «بانتظار صديقك» طويلاً: انتظر حتى 3 دقائق (إعادة محاولة
  تلقائية) وتأكد أن صديقك كتب الرمز صحيحاً.

## 🔐 الأمان والخصوصية

- الصوت والرسائل مشفّرة تلقائياً (DTLS/SRTP — معيار WebRTC) ولا تمر بأي سيرفر.
- سحابة PeerJS العامة ترى فقط رسائل التعارف التقنية لثوانٍ أثناء الاتصال.
- الغرفة تتطلب الرمز المكون من 4 حروف ولا ينضم لها شخص ثالث.

## 🛠️ البناء من الكود (اختياري)

```bash
# يتطلب: JDK 17 + Android SDK 34
./gradlew assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

مفتاح التوقيع المرفق (`app/gametalk.keystore`): كلمة السر `gametalk2026`.
للاستخدام الشخصي فقط — أنشئ مفتاحك الخاص لو نشرت على متجر Play.

## 📁 بنية المشروع

```
GameTalk/
├── android-app/app/src/main/java/com/gametalk/voice/
│   ├── MainActivity.kt      الواجهة العربية (إنشاء/انضمام/أذونات/حالة)
│   ├── BubbleService.kt     خدمة المكالمة: الفقاعة + نافذة الرسائل + بطاقة النسخ
│   ├── BubbleView.kt        الفقاعة «اثنان في واحد» (قائمة كتم/رسائل/إنهاء)
│   ├── CallEngine.kt        محرك WebRTC (Opus منخفض البت + DataChannel للرسائل)
│   ├── PeerSignaling.kt     الإشارة عبر سحابة PeerJS العامة (بدون خادم)
│   ├── Signaling.kt         واجهة طبقة الإشارة
│   └── CallBus.kt           الحالة المشتركة بين الخدمة والواجهة
├── signaling-server/        (اختياري) سيرفر ذاتي الاستضافة للشبكات المقيدة
├── releases/                ملفات APK الجاهزة
└── docs/                    دليل التشغيل السريع
```
