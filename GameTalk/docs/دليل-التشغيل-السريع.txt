  GameTalk — دليل التشغيل السريع (3 خطوات)
  مكالمة صوتية مع صديقك أثناء اللعب + فقاعة عائمة فوق اللعبة
═══════════════════════════════════════════════════════════

📦 الملفات:
  • GameTalk-v1.0.apk            ← التطبيق (ثبّته على الجهازين)
  • gametalk-signaling-server.zip ← سيرفر الربط (انشره مرة واحدة)
  • GameTalk-source-code.zip      ← الكود المصدري الكامل

───────────────────────────────────────────────────────────
الخطوة 1: انشر سيرفر الربط (مرة واحدة، 5 دقائق، مجاناً)
───────────────────────────────────────────────────────────
  1. فك ضغط gametalk-signaling-server.zip
  2. ارفع مجلد gametalk-signaling-server إلى مستودع في حسابك على GitHub
  3. ادخل render.com → سجل بـ GitHub → New + → Web Service
  4. اختر المستودع ثم: Build Command = npm install
                       Start Command = node server.js
                       Instance Type = Free
  5. انسخ الرابط الذي ستحصل عليه وحوّله إلى wss://
     مثال: wss://gametalk-signaling.onrender.com

  (الشرح المفصّل داخل ملف RENDER-DEPLOY-AR.md)

───────────────────────────────────────────────────────────
الخطوة 2: ثبّت التطبيق على الهاتفين
───────────────────────────────────────────────────────────
  1. أرسل GameTalk-v1.0.apk لصديقك (واتساب مثلاً)
  2. ثبّته على الجهازين (اسمح بـ«مصادر غير معروفة»)
  3. في أول تشغيل: فعّل زري الأذونات داخل التطبيق:
     🎤 الميكروفون + 🫧 العرض فوق التطبيقات
  4. في حقل «عنوان سيرفر الربط» ضع رابط wss:// الخاص بك

───────────────────────────────────────────────────────────
الخطوة 3: اتصلوا والعبوا!
───────────────────────────────────────────────────────────
  أنت:        «⚡ إنشاء غرفة جديدة» ← سيظهر رمز من 4 حروف
  صديقك:      يكتب الرمز ← «🤝 انضمام للغرفة»
  عند الاتصال: افتحوا اللعبة والعبوا — الفقاعة تبقى فوقها!

  الفقاعة:
    • لمسة        = كتم / تشغيل صوتك
    • سحب         = تحريكها
    • ضغط مطول    = زر إنهاء المكالمة
    • النقطة الملونة = جودة الاتصال (أخضر/أصفر/أحمر)

───────────────────────────────────────────────────────────
ملاحظات:
  • استهلاك الأنترنت ≈ 12 ميجا/ساعة فقط لكل طرف
  • الصوت مشفّر ويمتلك P2P مباشرة بين الهاتفين
  • السيرفر المجاني «ينام» بعد 15 دقيقة خمول — افتح رابطه
    في المتصفح قبل أول مكالمة ليستيقظ (30 ثانية)
  • إن وجدت أي مشكلة، وصف لي ما حدث وسأطور لك إصلاحاً
