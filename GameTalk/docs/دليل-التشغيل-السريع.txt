  GameTalk v1.2 — دليل التشغيل السريع
  مكالمة صوتية + فقاعة عائمة + رسائل سريعة فوق اللعبة
═══════════════════════════════════════════════════════════

🎯 الجديد في v1.2:
   • رسائل سريعة من الفقاعة العائمة! أرسل كود الغرفة
     لصديقك أثناء المباراة — تظهر عنده 4 ثوانٍ مع زر
     نسخ، ثم تختفي.
   • فقاعة «اثنان في واحد»: ضغطة = قائمة فيها زر
     كتم المايك وزر الرسائل.
   • أيقونة تطبيق احترافية جديدة (مايك نيون + فقاعة كلام).

───────────────────────────────────────────────────────────
الخطوة 1: ثبّت التطبيق على الهاتفين
───────────────────────────────────────────────────────────
  1. حمّل GameTalk-v1.2.apk (من مستودع GitHub أو من الرسالة)
  2. أرسله لصديقك (واتساب مثلاً) وثبّته على الجهازين
     (يُثبّت فوق v1.1 و v1.0 مباشرة بدون حذف)
  3. في أول تشغيل: فعّل زري الأذونات داخل التطبيق:
     🎤 الميكروفون + 🫧 العرض فوق التطبيقات

───────────────────────────────────────────────────────────
الخطوة 2: اتصلوا والعبوا!
───────────────────────────────────────────────────────────
  أنت:        «⚡ إنشاء غرفة جديدة» ← سيظهر رمز من 4 حروف
  صديقك:      يكتب الرمز ← «🤝 انضمام للغرفة»
  عند الاتصال: افتحوا اللعبة والعبوا — الفقاعة تبقى فوقها!

───────────────────────────────────────────────────────────
الفقاعة العائمة (اثنان في واحد):
───────────────────────────────────────────────────────────
  • ضغطة سريعة  = قائمة صغيرة: [زر الرسائل 💬] والفقاعة
  • ضغط مطول    = نفس القائمة + زر إنهاء المكالمة الأحمر
  • ضغطة على الفقاعة والموسعة = كتم / تشغيل المايك
  • سحب          = تحريكها (تتذكر مكانها)
  • النقطة الملونة = جودة الاتصال (أخضر/أصفر/أحمر)

───────────────────────────────────────────────────────────
الرسائل السريعة (أهم ميزة جديدة!):
───────────────────────────────────────────────────────────
  إرسال:
    1. اضغط الفقاعة ← اضغط الزر الأخضر 💬
    2. تفتح نافذة كتابة أعلى الشاشة مع الكيبورد
    3. اكتب مثلاً كود الغرفة: 7W2D
    4. اضغط زر الإرسال (أو زر «إرسال» في الكيبورد)
       — للإغلاق: اضغط زر ✕ أو اضغط خارج النافذة

  استلام:
    • تظهر بطاقة داكنة أعلى الشاشة فيها الرسالة
      + زر نسخ أزرق
    • اضغط على البطاقة أو زر النسخ ← يُنسخ النص
      فوراً — الصقه في اللعبة!
    • البطاقة تختفي تلقائياً بعد 4 ثوانٍ
    • مع كل رسالة: اهتزاز + نغمة قصيرة حتى لا تفوتك

  ملاحظة: الرسائل تصل فقط أثناء المكالمة المتصلة
  (تذهب مباشرة بين الهاتفين عبر قناة مشفّرة —
  لا تمر بأي سيرفر إطلاقاً)

───────────────────────────────────────────────────────────
ملاحظات:
  • استهلاك الأنترنت ≈ 12 ميجا/ساعة فقط لكل طرف
  • يعمل عبر أي شبكة: نفس الواي فاي أو واي فاي مختلف
    أو بيانات الهاتف — وأيضاً بين مدن وبلدان مختلفة!
    (الصوت P2P مباشر، والتعارف عبر سحابة PeerJS العامة
    المجانية 0.peerjs.com)
  • إذا تأخر الاتصال بعد إدخال الرمز: انتظر حتى 3 دقائق —
    التطبيق يعيد المحاولة تلقائياً. تأكد أن صديقك ضغط
    «إنشاء غرفة» وأن الرمز صحيح (4 حروف)
  • إن وجدت أي مشكلة، وصف لي ما حدث وسأطور لك إصلاحاً
