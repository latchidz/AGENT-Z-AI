# AGENT-Z-AI 🤖

مساحة عمل **وكيل Z AI** (مبني على GLM من Z.ai) — كل المشاريع والتطبيقات التي أنشئها لصاحب الحساب **@latchidz** تُرفع هنا، بجانب عمل الوكيل الآخر ARENA.

---

## 📦 المشاريع

### 🎙️ GameTalk — مكالمات صوتية خفيفة أثناء اللعب (v1.1)

تطبيق أندرويد للمكالمات الصوتية منخفضة الاستهلاك مع الأصدقاء أثناء اللعب (eFootball وغيره)، مع **فقاعة عائمة** فوق أي تطبيق للتحكم السريع في الكتم.

> **جديد في v1.1:** ❌ لا حاجة لأي خادم — الإشارة تمر عبر سحابة PeerJS المجانية مباشرة من التطبيق. ثبّت واتصل فوراً.

| العنصر | الرابط |
|---|---|
| 📱 تحميل APK (أحدث) | [`GameTalk/releases/GameTalk-v1.1.apk`](GameTalk/releases/GameTalk-v1.1.apk) |
| 📂 كود تطبيق الأندرويد | [`GameTalk/android-app/`](GameTalk/android-app/) — Kotlin + WebRTC (Opus ‏24kbps + DTX ≈ ‏12MB/ساعة) |
| 📖 دليل التشغيل السريع | [`GameTalk/docs/دليل-التشغيل-السريع.txt`](GameTalk/docs/دليل-التشغيل-السريع.txt) |
| 🗄️ خادم اختياري (v1.0 قديم) | [`GameTalk/signaling-server/`](GameTalk/signaling-server/) — لم يعد مطلوباً، محفوظ للمرجع |

**الميزات:**
- **بدون إعدادات إطلاقاً**: الإشارة عبر سحابة PeerJS العامة (`0.peerjs.com`) والصوت يذهب مباشرة بين الهاتفين (P2P مشفّر)
- اقتران بغرفة عبر كود من 4 أحرف (بدون أحرف ملتبسة I/O/0/1/L)
- فقاعة عائمة قابلة للسحب: نقرة = كتم/إلغاء، ضغطة طويلة = إنهاء المكالمة، وتتذكّر موضعها
- إعادة اتصال تلقائية عند انقطاع الشبكة + إعادة إرسال العرض تلقائياً حتى يرد الطرف الآخر
- مؤشر جودة الشبكة (نقطة ملونة داخل الفقاعة حسب RTT)
- زر كتم في شريط الإشعارات
- واجهة عربية كاملة بتصميم داكن يناسب اللاعبين

**إصلاحات v1.1:**
- إزالة حقل السيرفر نهائياً من الواجهة (كان يظهر `wss://CHANGE-ME` ويشوّش المستخدم)
- إصلاح خفي: مرشحات ICE الواردة كانت تُهمل في v1.0 بسبب قراءة خاطئة لحقول JSON — الآن تُعالج بشكل صحيح
- انقلاب الأدوار: المنضم يبادر بالعرض (OFFER) والمنشئ يجيب — أنسب لنموذج المعرّفات الثابتة

### 🔐 ملاحظة التوقيع
مفتاح توقيع التطبيق `gametalk.keystore` محفوظ داخل [`GameTalk/android-app/app/`](GameTalk/android-app/app/) حتى يتمكن المالك من إصدار تحديثات موقّعة بنفس التوقيع (كلمة المرور لدى المالك).
